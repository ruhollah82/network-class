# 📚 جزوات درس شبکه‌های کامپیوتری

**استاد:** دکتر مهرناز مودی
**گردآورنده:** روح‌اله ناصری
**نیم‌سال:** زمستان ۱۴۰۴

---

## 📖 معرفی

این مخزن شامل جزوات ساختارمند درس «شبکه‌های کامپیوتری» در ۱۷ جلسه آموزشی است. هدف آن ارائه مرجعی منظم برای یادگیری مفاهیم شبکه، مرور سریع مطالب و آمادگی برای امتحانات می‌باشد.

---

## 📁 ساختار مخزن

- **`Mark Down/`**
  جزوات اصلی در قالب Markdown، مناسب مطالعه آنلاین و جستجوی سریع.

- **`PDF/`**
  نسخه PDF جلسات برای چاپ و مطالعه آفلاین.

---

## 🎯 سرفصل‌های آموزشی

- مبانی شبکه و معماری اینترنت
- مدل‌های OSI و TCP/IP
- لایه‌های شبکه: فیزیکی، پیوند داده، شبکه، انتقال و کاربرد
- پروتکل‌ها (TCP، UDP، HTTP، FTP، SMTP، DNS و …)
- امنیت شبکه و مدیریت شبکه
- شبکه‌های بی‌سیم و پروتکل‌های پیشرفته
- مفاهیم نوین مانند IPv6، SDN و NFV
- ارزیابی عملکرد و QoS
- مرور و جمع‌بندی نهایی

---

## 📚 محتوای جلسات

جزوات شامل ۱۷ جلسه متوالی از مبانی تا مفاهیم پیشرفته شبکه است. هر جلسه شامل توضیح مفاهیم، مثال‌های کاربردی و نکات مهم آموزشی می‌باشد.

---

## 🚀 نحوه استفاده

- **مطالعه آنلاین:** استفاده از فایل‌های Markdown با ابزارهایی مانند VS Code یا Obsidian
- **مطالعه آفلاین یا چاپ:** استفاده از نسخه‌های PDF
- **پیشنهاد:** مطالعه جلسات به ترتیب آموزشی برای درک پیوسته مفاهیم

---

## 🤝 مشارکت و بازخورد

برای پیشنهاد، اصلاح یا گزارش خطا از بخش Issues یا Pull Requests در GitHub استفاده کنید.

---

## 📜 حقوق استفاده

محتوای آموزشی متعلق به استاد درس بوده و تنها گردآوری و تنظیم توسط من انجام شده است. استفاده صرفاً با اهداف آموزشی توصیه می‌شود.
